# シミュレーション仮定値

この文書は、完全合成のMVP設定と、公表情報を地域文脈として使う印西プロファイルの仮定値を整理します。観測値そのものは[公的資料](sources.md)へ分離し、ここで仮定値と同一視しません。

## `examples/mvp.toml`

| 項目 | 仮定値 |
|---|---:|
| 期間 | 90日 |
| 人口 | 100,000人 |
| 1人あたり上水需要 | 250 L/人/日 |
| 初期貯水量 | 350,000,000 L |
| 貯水容量 | 400,000,000 L |
| 基本水源補給 | 22,000,000 L/日 |
| 渇水倍率 | 通常年の0.55 |
| データセンター | 3施設（30、25、20 MW） |
| 稼働率 | 0.80、0.75、0.85 |
| WUE | 1.20、1.10、1.00 L/kWh |
| 基準ケースの再生水比率 | 0% |
| 感度分析 | 0%、2%、25%、50% |
| 自治体制限倍率 | 上水要求の75% |

月別水源倍率、施設稼働開始日、蒸発・ブローダウン・返流・回収可能排水の各比率も合成値です。

2%ケースは、令和4年度の全国の下水処理水放流量に対する場外再生水利用が2%未満だったという背景を見やすくするための感度点です。データセンターの実測再生水比率、全国平均、推奨値を意味しません。再生水インフラなしの基準ケースは引き続き0%です。

## 解釈

MVPの値は、計算経路、境界条件、比較出力、エージェント連携を確認するために意図的に単純化しています。出力に不足が現れても、その不足が現実のどこかで起こる確率や規模を示しません。

実地域へ適用する場合は、少なくとも人口動態、料金用途別需要、日別取水可能量、貯水運用、送配水損失、環境流量、施設の実測WUE、上水・再生水契約、排水経路、渇水ルールを地域資料へ置換してください。

## `configs/inzai_chiba_new_town.toml`

印西プロファイルの主な比較期間は2026年6月1日〜9月10日の102日間です。公表値を使う項目と合成仮定を、設定コメントと`docs/sources.md`で明示的に区別します。

公表値から夏季計算へ参照値として採用したもの:

- 令和6年度千葉県営水道の一人一日平均給水量280 L/人/日
- 2026年7月末の印西市3NT地区人口合計70,760人（給水区域人口の近似）
- 令和6年度の北総浄水場配水池有効容量48,000 m³（48 ML）。ただし、この公表容量を地域配水バッファの境界へ転用することは下記の仮定を伴う

画面とログへ併記するが、水収支の流入・配分へ使用しない観測コンテキスト:

- 2025年6月1日〜9月10日の我孫子アメダス日降水量102件、期間合計394.5 mm。印西周辺の気象コンテキストであり、上流ダム流域の雨量や上水流入ではない
- 2025年6月1日〜9月11日の利根川上流9ダム10日値。観測日の間は画面表示用に線形補間するが、補間値は観測値ではない。9ダム全量を印西向け在庫や供給可能量として扱わない

2026年9月10日は成果物作成時点より後なので、2026年の完結実績ではなく、2025年の同じ月日の値を2026年仮想シナリオへ併記します。これは年の置換、2026年の予報、平年値ではありません。

依然として仮定値であるもの:

- 北総浄水場の公表容量48 ML全体を、この概念モデルの地域配水バッファ容量代理値とすること。実施設は印西市以外にも給水するため、印西専用容量を意味しない
- 2026年6月1日に地域配水バッファが満水の48 MLで始まること。公表資料から確認したのは有効容量であり、当日の実貯留量ではない
- 県営水道全体の平均給水量から計算する合成基準供給と、10.5%の通常時供給余裕。印西専用枠の実測値ではない
- 月別需要形状と、渇水時の基準供給倍率93%
- 3施設のIT負荷、稼働率、WUE、施設内水用途比率、およびD31（7月1日）、D46（7月16日）、D62（8月1日）の稼働開始日
- 250MW IT負荷感度。実在・発表済み施設の受電容量を示す値ではない
- D62（8月1日）供用とした比較用配水池増設20 ML、外部初期充水10 ML。48 MLの代理容量へ加える反実仮想で、実際の増設計画ではない
- DC敷地内水槽300万L
- 再生水25%・50%の専用供給が存在するという感度仮定。2%も国内DC実績値ではない

降水量と9ダム貯水量は観測コンテキストとして読み込みますが、地域配水バッファの流入、容量、初期量、配分可能量には使いません。画面にある9ダムの反実仮想差は、広域観測系列へ仮想DCの累積上水消費を重ねた診断表示であり、実際の北総・印西向け配分計算ではありません。通常条件のDCなしを維持できるよう較正した合成基準供給へDC需要を追加し、同じ条件で政策・施設規模・再生水・配水池の差を比較します。
