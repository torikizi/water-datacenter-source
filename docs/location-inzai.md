# 立地プロファイル: 印西市・千葉ニュータウン

## シミュレーション境界

対象は「印西市全域」ではなく、千葉ニュータウンを中心とする県営水道給水区域の概念モデルです。主な比較期間は2026年6月1日〜9月10日の102日間です。県営水道の令和6年度平均給水量、2026年7月末のNT地区人口、北総浄水場配水池の公表容量48,000 m³を参照します。ただし、48 MLを印西の地域配水バッファ代理値として満水開始させること、印西専用の供給量、施設負荷、WUE、冷却方式は仮定です。結果は現実の印西市の需給予測ではありません。

成果物作成時点では2026年9月10日が未来なので、画面には2025年6月1日〜9月10日の我孫子日降水量と、2025年6月1日〜9月11日の利根川上流9ダム10日値を同じ月日に対応させて併記します。2025年の観測コンテキストは2026年の実績・予報ではなく、水収支の流入や配分にも使いません。

印西市内には印西市水道、千葉県営水道、長門川水道企業団の3事業体があります。千葉ニュータウン地域は主に千葉県営水道の給水区域であるため、この範囲に限定します。

## データセンター立地の文脈

千葉県の基本計画は、印西市を大規模データセンターの集積地として位置づけ、地盤、東京都心からの距離、成田空港への近接、電力・通信インフラを立地上の条件として挙げています。

- [地域未来投資促進法に係る千葉県の基本計画](https://www.pref.chiba.lg.jp/keisei/keizaitaisaku/chiikimirai/kihonkeikaku.html)
- [印西市都市計画審議会会議録](https://www.city.inzai.lg.jp/cmsfiles/contents/0000021/21322/kaigiroku.pdf) — 景観・騒音等への懸念と土地利用調整

モデル上は住宅地の中に個別施設を置くのではなく、業務系地区にある複数施設が住宅地と同じ水道系統を共有すると仮定します。

## 三つの貯留層

1. 広域水源: エンジンが任意で水収支へ組み込める層。夏季版では無効。2025年9ダム値は別の観測コンテキストとして表示するだけで、配分元にしない
2. 地域配水バッファ: 浄水後の上水を貯留する現在の計算層。北総浄水場配水池の公表容量48 MLを容量代理値とし、6月1日に満水の48 MLで開始すると仮定する。北総配水池は印西専用ではなく、満水開始も実測値ではない
3. DC敷地内水槽: 施設の短期需要を時間移動する感度層。累積水源量は増やさない

配水池増設時の初期充水を設定した場合、その水は`reservoir_commissioning_fill_l`として外部流入に明示し、水収支へ含めます。これにより、空の貯水池増設と、水を蓄えた状態での供用開始を混同しません。

## 夏季系列

通常条件の基準供給は、県営水道全体の平均給水量を需要参照にし、合成した月別需要形状と10.5%の供給余裕から算出します。印西専用の観測供給量ではありません。渇水条件はこの基準供給へ93%倍率を掛けた合成ストレスです。

2025年の我孫子日降水量は期間合計394.5 mmです。日降水量と9ダム10日値を表示用に読み込みますが、河川流量、ダム流入・放流、北総への配分、取水制限との因果系列は構成していません。我孫子の雨は上流ダム流域の雨を表さず、観測雨量を上水流入へ換算しません。

したがって「通常」「渇水」は2025年の観測天候の分類でも、2026年夏の天候再現や予報でもなく、同じ102日間でDC条件だけを比較する合成シナリオ名です。実データへ適用する場合は、北総系の各水源、木下取水、北総浄水・配水、対象区域需要を同じ年・日付でそろえた系列へ差し替える必要があります。
