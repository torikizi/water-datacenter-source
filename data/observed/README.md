# 観測コンテキストデータ

このディレクトリには、公的ページから転記した変更しない観測値を置きます。モデル用の仮定値や変換係数とは分離します。

## 我孫子アメダスの日降水量

- ファイル: `jma_abiko_daily_precipitation_2025-06-01_2025-09-10.csv`
- 観測所: 気象庁 我孫子（千葉県、観測所番号45061／検索ブロック0376）
- 期間: 2025年6月1日〜9月10日
- 単位: mm/日
- 102日間の合計: 394.5 mm（保存した日別値の合計）
- 用途: 印西周辺の気象コンテキスト表示のみ
- 水収支への扱い: 上水流入へ変換しない

月別の原表:

- [2025年6月](https://www.data.jma.go.jp/stats/etrn/view/daily_a1.php?block_no=0376&month=06&prec_no=45&year=2025)
- [2025年7月](https://www.data.jma.go.jp/stats/etrn/view/daily_a1.php?block_no=0376&month=07&prec_no=45&year=2025)
- [2025年8月](https://www.data.jma.go.jp/stats/etrn/view/daily_a1.php?block_no=0376&month=08&prec_no=45&year=2025)
- [2025年9月](https://www.data.jma.go.jp/stats/etrn/view/daily_a1.php?block_no=0376&month=09&prec_no=45&year=2025)
- [気象庁 地域気象観測所一覧](https://www.jma.go.jp/jma/kishou/know/amedas/ame_master_20241218.pdf)

我孫子は印西周辺の気象参照点として選んだ観測所であり、気象庁が「印西の最寄り」と指定したものではありません。また、北総系の上流ダム流域の降水を代表しません。降水量を上水量へ変換するには、集水面積、流出率、取水可能率、浄水歩留まり、時間遅れなどの未取得パラメータが必要です。したがって、この系列を地域配水バッファへ直接加算しません。

## 利根川上流9ダムの確定値

- ファイル: `tone_upper_9_reservoirs_2025_10day.csv`
- 提供者: 独立行政法人水資源機構
- 期間: 2025年6月1日〜9月11日、10日ごとの確定値
- 単位: `capacity_1000m3`、`storage_1000m3` は千m³
- 用途: 広域水源の観測コンテキスト。画面では仮想DCの累積上水消費を重ねた診断差も表示できる
- 地域配水への扱い: 印西専用在庫や日別供給可能量として使わない

各行の原表は、次の固定URL形式で確認できます。

`https://www.water.go.jp/honsya/honsya/suigen/junpo/past/2025/junpoYYYYMMDD.html`

例:

- [2025年6月1日](https://www.water.go.jp/honsya/honsya/suigen/junpo/past/2025/junpo20250601.html)
- [2025年9月11日](https://www.water.go.jp/honsya/honsya/suigen/junpo/past/2025/junpo20250911.html)

7月は洪水期の制限容量へ移るため、公表容量の分母が変わります。ゲームでは公表された貯水率を観測点としてつなぎ、観測日の間は表示用に線形補間します。補間値は観測値ではありません。診断差も、北総・印西への実配分や実際のダム運用を再現するものではなく、水収支計算へ戻しません。

## 北総浄水場配水池の容量

- 公表値: 有効容量48,000 m³（16,000 m³×3池）
- 出典: [千葉県営水道 令和6年度事業年報「20 施設概要」](https://www.pref.chiba.lg.jp/suidou/souki/toukeidata/documents/r6-20.pdf)
- モデル上の扱い: 48 MLを地域配水バッファの容量代理値とし、2026年6月1日に満水で開始

公表資料が示すのは北総浄水場の施設容量です。北総浄水場は千葉ニュータウン以外にも給水するため、48 MLは印西専用在庫ではありません。また、満水開始はシミュレーションの初期条件であり、同日の実貯留量ではありません。このディレクトリには実貯留量の時系列がないため、容量値と観測貯水系列を混同しないでください。

## 2025年と2026年の対応

水収支シナリオは2026年6月1日〜9月10日ですが、成果物作成時点では2026年9月10日が未来です。このため、完結している2025年の観測系列を日番号・月日で対応させ、2026年の仮想シナリオの背景へ表示します。画面とJSONLではシミュレーション日付と観測参照日付を別フィールドに保存します。2025年値は2026年の実績、予報、平年値ではありません。

## 重要な境界

北総浄水場は利根川表流水を水源とし、北総系には利根川河口堰、川治ダム、湯西川ダム、奈良俣ダムが関係します。利根川上流9ダム系列に含まれるのはこのうち奈良俣ダムだけであり、川治・湯西川は鬼怒川4ダム側、河口堰は単純なダム貯水量系列ではありません。9ダム全量は北総系統全体でも印西市専用でもありません。

我孫子の降水と9ダム貯水は同じ「雨→印西向け上水」の因果系列として結合せず、別々の参考情報として表示します。どちらも`source_inflow_l`や住民・DCへの配分量を変えません。
